## What got in the way

- **The laptop has no `.env.local`**, so nothing that needs a model key can run here. The models lane
  is blocked on that for its fair speed comparison.
- **`ship.mjs` v1 could not ship a NEW folder** (found by the accounts lane). It committed correctly,
  then refused to push. Fixed in v2 (scenario 1).
- **Editing a file in a commit's path list while its gate runs put the edit into that commit
  unreviewed.** v2 refuses that now (a named file changed during the gate stops it before the commit).
- **Two lanes' gates share one `node_modules/.cache`** through the worktree junctions. A test:engine
  bundle written by one lane can be run by another's gate mid-flight. It is rare (the window is about a
  second), but not impossible.
