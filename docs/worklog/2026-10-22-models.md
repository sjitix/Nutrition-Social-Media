# 2026-10-22 — models lane: the key in, Nemotron measured, and the fast finish justified

**Mandate (owner, updated today):** "i like nemotron, id be happy if we could make it work". The goal is to make
Nemotron-3-Ultra 550B fast and correct enough to run the assistant; other models are fallbacks.
**Solved:** partly. The setting is decided (reasoning off plus the fast finish, about 2.8 times faster at no
loss), and the fast finish shipped (v1, `b2b4285`). The evals can now run it (arms N and convoN), though no model
run has used them yet. The diagnosis covers 8 of 9 clusters. NVIDIA's free endpoint turned out to be for testing
only. Next come the diagnosis's harness corrections, then the speed range on the charger.

## What got in the way

- **The laptop sleeps during long runs.** A five-minute convo arm took five hours, and messages that span a
  sleep are timed as hours. The harness now keeps those out of the seconds (above). A lid closed by hand still
  sleeps the machine, because the lock cannot stop that: the run pauses until the lid opens, and a call dropped on
  waking is retried.
  The battery is the other limit: it fell from 34% to 22% in 25 minutes of control runs, so a timed run waits
  for the charger.
