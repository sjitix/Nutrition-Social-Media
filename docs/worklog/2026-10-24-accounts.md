## What moved

- **`3b1e483`: a profile's `removedAllergies` is checked before it imports or syncs.**
  - **The field:** v1's F7 adds `removedAllergies` to the profile: allergies the person took off by
    hand, so an old chat mention cannot put them back. v1 settled its shape on 2026-10-23 as a list of
    strings.
  - **The gap:** `checkProfileExtras` ignores fields it does not know. A value in any shape would have
    come in from a file, or been mirrored to every device, unchecked.
  - **Why it matters:** this field decides whether an allergy is honoured. A file or account row whose
    `removedAllergies` is not a list of strings is now refused, and the device keeps its own copy.
    Lowercasing stays with v1: the check takes any string.
  - **Tests:** two cases are refused, a string and a list holding a number. The complete profile now
    carries one, and still passes. A mutation removing the check turns that test red (115 mutations).

- **The gateway's one-shots no longer accept any path** (deferred on 2026-10-22). An empty or mistyped
  path would have matched every request, the run's own log reads among them. The gateway now refuses
  an arm for a path it does not proxy (400). `live.mts` stops at a refused arm rather than run the step
  unarmed, and its last bare arm, Pho's lost request, goes through the same helper. Live run:
  55/55.
