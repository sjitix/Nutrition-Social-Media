# Midjourney prompts — the week plan screen

The core screen: seven days, three meals each, recipe names, calories and protein.
Every prompt opens with the same flat-webpage framing as the general set.
1–4 have recipe images, 5–8 have none, same layouts otherwise, so the difference is visible
rather than guessed at.
