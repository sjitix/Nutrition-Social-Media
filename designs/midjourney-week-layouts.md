# Midjourney prompts — week plan layouts

Fourteen different ways to show the same thing: seven days, three meals each, dish names, calories
and protein. Every prompt holds the sage palette and the flat-webpage framing constant, so the only
variable is the **structure**. Run them, keep what your eye stops on.

---

## 1 — Seven columns (what is live now, for comparison)

```
flat 2d web page design, straight on front view, orthographic, fills the entire frame edge to edge, beautiful modern nutrition and meal planning weekly plan, soft sage green ground, seven columns one per day, three dish names in each with calories and protein, totals along the bottom --ar 16:9 --style raw --no tilted, angled, perspective, 3d, shadow, mockup, device, monitor
```
