# Midjourney prompts — wide exploration

`--chaos` controls how different the four images in one grid are from each other. Default is 0,
which is why grids come back as near-identical variations. These run it high, and stay deliberately
loose about layout so there is room for Midjourney to answer differently four times.

`--chaos 100` is the widest. Drop to 50 for four related-but-distinct answers, or 25 to explore
inside one direction.

---

## 1 — Wide open

```
flat 2d web page design, straight on front view, orthographic, fills the entire frame edge to edge, beautiful modern nutrition and meal planning weekly plan, dish names with calories and protein, seven days --ar 16:9 --style raw --chaos 100 --no photo, thumbnail, illustration, icon, tilted, angled, perspective, 3d, shadow, mockup, device, monitor
```
